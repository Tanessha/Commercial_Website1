# Commercial Website (CSS Flexbox)

A responsive commercial website built using HTML5 and CSS Flexbox layout.

## Features
- **Header & Navigation Bar**: Responsive flexbox navbar with navigation links and shopping cart badge.
- **Hero Section**: Promotional banner showcasing next-gen commercial tech products.
- **Products & Services**: Flexbox grid displaying commercial product cards and enterprise services.
- **About Us Section**: Statistics and company mission layout.
- **User Account Dashboard**: Interactive login form and membership benefits.
- **Contact Details**: Contact form and company location info.
- **Footer**: Social media links and copyright details.

## Tech Stack
- HTML5
- CSS3 (Flexbox Layout)
- FontAwesome Icons
